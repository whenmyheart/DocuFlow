# 문서체크

민원·행정 부서 실무자가 신청서의 필수 항목 누락을 배포 전에 확인하고 즉시 수정하는 1-Day 프로토타입입니다.

현재 검토 결과는 실제 AI가 아닌 브라우저 내부의 규칙 기반 예시이며, 입력 내용은 저장하거나 외부로 전송하지 않습니다. 테스트에는 가상 샘플 데이터만 사용합니다.

## 실행

Node.js 22.13.0 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 확인

```bash
npm run build
npm run lint
npm test
```

## 구현 범위

- 세분화된 필수 항목 입력
- 빈 입력 안내 및 규칙 기반 누락 탐지
- 누락 항목과 판단 근거 표시
- 첫 누락 항목으로 이동, 즉시 수정 및 재검토
- 가상 샘플과 부서 피드백 확인 메모

문서 검색, 문장 다듬기, 실제 AI 연동, 데이터 저장은 포함하지 않습니다.
