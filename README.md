# 문서체크

민원·행정 부서 실무자가 새 신청서 양식의 본문 전체를 한 곳에 입력하고, 안내했지만 실제로 기재하지 않은 정보를 배포 전에 확인하는 1-Day 프로토타입입니다.

현재 검토 결과는 실제 AI가 아닌 브라우저 내부의 규칙 기반 예시이며, 입력 내용은 저장하거나 외부로 전송하지 않습니다. 테스트에는 가상 샘플 데이터만 사용합니다.

## 실행

Node.js 22.13.0 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 확인

```bash
npm run build
npm run lint
npm test
```

## 구현 범위

- 신청서 양식 전체 본문을 입력하는 단일 텍스트 영역
- 문의처, 사이트, 신청 기간, 제출처, 첨부서류, 비용을 안내했지만 실제 정보가 없는 경우 오류 탐지
- 수정 예시와 동일한 문구가 아니어도 담당 기관명, 다양한 전화번호·날짜·주소·금액 표현을 인식
- 첨부 파일명과 줄바꿈 서류 목록, `1만원`·`오천 원`·`비용 없음` 등 다양한 첨부서류·비용 표현을 인식
- 오류 판단에 사용한 본문 문장과 수정 예시 표시
- 첫 누락 항목으로 이동, 즉시 수정 및 재검토
- 가상 샘플과 부서 피드백 확인 메모

문서 검색, 문장 다듬기, 실제 AI 연동, 데이터 저장은 포함하지 않습니다.
